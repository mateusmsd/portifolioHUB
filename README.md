# Portfólio — Mateus Melo

Este repositório apresenta o meu portfólio pessoal, desenvolvido para centralizar projetos, habilidades e informações profissionais em um único lugar. O objetivo é demonstrar minhas competências técnicas, experiência prática e evolução como desenvolvedor.

## Sobre o Projeto

O Portfólio HUB foi criado com foco em simplicidade, organização e fácil navegação. Ele reúne projetos, informações pessoais e formas de contato, permitindo que recrutadores e colaboradores conheçam melhor meu trabalho.

## Funcionalidades

- Página inicial com apresentação pessoal  
- Seção de projetos desenvolvidos  
- Layout responsivo para diferentes dispositivos  
- Interface simples e objetiva  
- Organização centralizada dos trabalhos  
- Navegação rápida entre seções  

## Tecnologias Utilizadas

- HTML  
- CSS  
- JavaScript  
- GitHub Pages (deploy)  

## Estrutura do Portfólio

- **Home** — Apresentação e visão geral  
- **Projetos** — Lista dos trabalhos desenvolvidos  
- **Sobre** — Informações profissionais  
- **Contato** — Formas de comunicação  

## Objetivo

Este portfólio foi desenvolvido para:

- Apresentar meus projetos  
- Demonstrar minhas habilidades  
- Servir como currículo online  
- Centralizar meus trabalhos  
- Facilitar contato profissional  

## Responsividade

O site foi desenvolvido para funcionar em:

- Computadores  
- Tablets  
- Smartphones
